Runtime settings

STT Backend

Choose how Murdock obtains transcripts: proxy to an upstream Wyoming STT service, or transcribe directly via the Mistral Cloud API (Voxtral).

Emotion detection (experimental)

Classifies the emotional tone of verified speech (happy, sad, angry, …) and pushes it to Home Assistant. This is plumbing only — no compatible ONNX model ships with Murdock yet. The toggle can be pre-flipped safely.

Per-satellite thresholds

Override the verify threshold for individual satellites (e.g. a noisy kitchen speaker vs. a quiet study). Leave empty to fall back to the global setting above.

Media restrictions (per satellite × source)

Set how much each media source tightens the verify threshold for each satellite while it's playing — e.g. the living-room TV restricts the living-room satellite strongly, but a bedroom radio not at all. Needs the media + satellite MQTT automations (see the MQTT card). Sources with no rule fall back to the default boost when they play in the satellite's room.

Confidence calibration

Maps the raw cosine distance to a calibrated probability (Platt scaling) so the confidence reported to Home Assistant is meaningful. Fitted automatically from your enrolled samples; gating still uses the distance threshold.

MQTT (recommended)

Publish speaker-recognition results over MQTT. Entities appear automatically in Home Assistant via discovery — no token, no manual helpers. Home Assistant can also push context (TV state, presence) back to Murdock on retained context topics.

Sample quality (advanced)

Adjust how sample quality is scored. Scores drive the smart auto-enroll replacement logic (worst sample is only replaced when a better one comes in) and the per-speaker training quality indicator. Weights are normalized automatically.
